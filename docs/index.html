Introduction

API REST de VERGEL para la gestión de clientes, suscripciones, servicios, cotizaciones, billeteras y puntos de lealtad. Operaciones orientadas a El Salvador (DTE, DUI, NRC, IVA).

Base URL: http://localhost

Esta documentación describe los endpoints disponibles en la API de VERGEL.

Para consumir los endpoints protegidos necesitas un token de acceso. Envíalo como cabecera `Authorization: Bearer {token}`.

Todos los endpoints requieren autenticación salvo que se indique lo contrario.

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_AUTH_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Los tokens se generan mediante Laravel Sanctum. Para obtener tu token, inicia sesión en la aplicación y emite un nuevo token de acceso.

Consultas

Listar y filtrar clientes.

requires authentication

Obtiene una lista paginada de clientes con opciones de búsqueda y filtros.

Example request:
curl --request GET \
    --get "http://localhost/api/v1/customers?search=architecto&status=active&phone=architecto&desde=architecto&hasta=architecto&limit=15" \
    --header "Authorization: Bearer {YOUR_AUTH_TOKEN}" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost/api/v1/customers"
);

const params = {
    "search": "architecto",
    "status": "active",
    "phone": "architecto",
    "desde": "architecto",
    "hasta": "architecto",
    "limit": "15",
};
Object.keys(params)
    .forEach(key => url.searchParams.append(key, params[key]));

const headers = {
    "Authorization": "Bearer {YOUR_AUTH_TOKEN}",
    "Content-Type": "application/json",
    "Accept": "application/json",
};


fetch(url, {
    method: "GET",
    headers,
}).then(response => response.json());
